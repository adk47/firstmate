# Product Naming (mandatory)

Correct product names to use in every written output.

- *Muso Ads* = the advertiser platform (access.muso.ai). Never "B2B", never "Muso
  Access" (former name).
- **Tiers are Lite / Pro / Business.** There is **no "Business Pro"**.
- **Amp** — short for **Amplify**, the personalised career feed in the Muso app. **Not
  an acronym**: never write "AMP", "AMPlify", "Ad Measurement Platform", or "Accelerated
  Mobile Pages". Amp is user-side; Muso Ads is advertiser-side.
